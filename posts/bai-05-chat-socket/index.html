Bài 05 – Ứng dụng Chat Client – Server bằng Java

December 22, 2025

1. Mô tả bài toán#

Ứng dụng Chat Client – Server cho phép các máy tính trong mạng trao đổi tin nhắn với nhau thông qua giao thức TCP Socket.

2. Nguyên lý hoạt động#

  • Server mở cổng và chờ kết nối
  • Client kết nối đến Server
  • Client gửi tin nhắn
  • Server nhận và hiển thị tin nhắn

3. Ý nghĩa trong lập trình mạng#

Bài toán Chat giúp sinh viên hiểu rõ:

  • Cách truyền dữ liệu thời gian thực
  • Cách xử lý kết nối mạng giữa nhiều máy
  • Nguyên lý giao tiếp Client – Server
