Bài 08 – WebSocket và giao tiếp thời gian thực

December 25, 2025

1. WebSocket là gì?#

WebSocket là giao thức cho phép thiết lập kết nối hai chiều giữa Client và Server thông qua một kết nối TCP duy nhất.

2. Đặc điểm của WebSocket#

  • Kết nối hai chiều (full-duplex)
  • Phù hợp cho ứng dụng thời gian thực
  • Giảm độ trễ so với HTTP truyền thống

3. Ví dụ WebSocket Client (JavaScript)#

const ws = new WebSocket("ws://localhost:8080");

ws.onopen = () => {
    console.log("Đã kết nối tới WebSocket Server");
};

ws.onmessage = (event) => {
    console.log("Server gửi:", event.data);
};

ws.onclose = () => {
    console.log("Kết nối đã đóng");
};
