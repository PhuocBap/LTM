Bài 04 – Java RMI và gọi phương thức từ xa

December 21, 2025

1. Java RMI là gì?#

RMI (Remote Method Invocation) là cơ chế cho phép một chương trình Java gọi phương thức của đối tượng đang chạy trên một máy khác trong mạng.

2. Nguyên lý hoạt động#

  • Client gọi phương thức từ xa
  • Server thực thi phương thức
  • Kết quả được trả về qua mạng

3. Interface từ xa trong RMI#

import java.rmi.Remote;
import java.rmi.RemoteException;

public interface Hello extends Remote {
    String sayHello() throws RemoteException;
}
